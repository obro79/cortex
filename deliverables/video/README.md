# Cortex hackathon video package

This package contains a recording-ready, 72-second **deterministic-fixture** teaser for Cortex. It is intentionally text-first so it is reliable to render locally and easy to replace with screen capture in an editor.

## Audience-safe claims

- Every provider name, record, timestamp, query result, and gate outcome shown here is local deterministic fixture data. Nothing shown is a live provider connection or live customer data.
- The demo does **not** claim native Claude session resume or fork.
- The handoff shown is an **opt-in portable bundle**, with `session_accessed: false`.

## Deliverables

- `cortex-hackathon-fixture-teaser.mp4` — 1280×720 H.264 teaser (generated; 72 s; no audio).
- `storyboard.md` — capture plan and on-screen truth constraints.
- `narration.md` — paced speaker script, about 72 seconds.
- `captions.srt` — burned into the generated teaser and reusable in an editor.
- `artifact-manifest.json` — build metadata and checksum, regenerated by the build script.

## Rebuild / validate

From the repository root:

```bash
bash scripts/build_hackathon_video.sh
```

The builder requires an installed `ffmpeg` and `ffprobe`. It verifies the rendered duration, resolution, codec, and absence of audio; then writes the manifest. This video has no soundtrack by design: use `narration.md` for a live or recorded voice-over, or replace scenes with actual app capture while retaining the fixture disclosure card.

## Editing guidance

Keep the 4-second disclosure at the beginning and do not crop the persistent “DETERMINISTIC FIXTURE DEMO · NO LIVE PROVIDERS” label. If replacing a scene with a browser capture, show the local fixture seed/reset state and retain labels that distinguish it from a live provider integration.
