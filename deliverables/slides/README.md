# Cortex hackathon deck

`cortex-hackathon-demo.pptx` is an eight-slide, 16:9 editable PowerPoint deck.
It is generated from editable text and shapes by
`scripts/build_hackathon_deck.mjs`; the generator intentionally has no npm
dependencies. Rebuild with:

```bash
node scripts/build_hackathon_deck.mjs
```

The deck is fixture-only. Keep the **SYNTHETIC FIXTURES / NOT LIVE** disclosure
when adapting it, unless the evidence boundary has materially changed and has
been independently validated.
