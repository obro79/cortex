# Provider connector assets

Prototype connector-card PNGs captured on 2026-07-23.

- Slack is the PNG linked from Slack's official media kit.
- GitHub, Atlassian, Jira, Google Drive, Gmail, and Anthropic marks
  are PNG derivatives rendered from Simple Icons SVGs.
- `provider` is the precise visual identity. `backend_provider` is the canonical
  ingestion identifier used by Cortex; Atlassian is a connector-family asset
  and therefore has no direct backend provider.
- Gmail is not a generic email mark, and the Anthropic mark is not presented as
  an official Claude Code logo. Product cards may describe the connected data
  below the vendor name, but must not relabel either mark.
- The third-party SVG derivatives are temporary implementation assets. Before
  public launch, compare them with the current official brand libraries and
  replace any asset whose vendor guidelines require a supplied binary.
- Do not recolor, distort, crop into a different symbol, or imply vendor
  endorsement.
- Display provider names beside these marks; icons are decorative in that
  context.

See `manifest.json` for source URLs, dimensions, and SHA-256 hashes.
